# 0.5. Assistants

### Which AI assistant should I use with this course?

Use the AI coding agent you already work with. A coding agent can explain a lesson, review your code, and edit the files in your own project. This course does not ship a dedicated assistant: it gives your agent the guidance it needs to follow the practices taught here.

### How do I teach my coding agent the practices of this course?

Give it two complementary sources of guidance:

- **`AGENTS.md`**: the open, tool-agnostic file that tells any coding agent your project's exact commands, definition of done, conventions, and layout. [6.2. Readme](../6. Sharing/6.2. Readme.md#what-is-agentsmd) explains what belongs in it, what it deliberately cannot enforce, and how to keep it from drifting away from your code.
- **[MLOps Coding Skills](https://github.com/fmind/mlops-coding-skills)**: the methodology of this course packaged as [Agent Skills](https://agentskills.io/home), one skill per chapter, that your agent loads on demand. The repository README explains how to install them for your agent.

### What are some effective ways to use the assistant?

To maximize your learning, use your agent as an interactive partner. For instance:

- **Conceptual Clarity:** "Explain the difference between CI/CD and CML."
- **Code Implementation:** "Show me a Python code snippet for a basic DVC pipeline."
- **Best Practices:** "What are the key considerations for versioning a machine learning model?"
- **Code Reviews:** Point your agent at a script and ask, "Can you review this Python script and suggest improvements for production readiness?"

### Should I trust the assistant's answers completely?

Your agent can make mistakes or suggest code that does not match your environment. Check important claims against the course, official documentation, and your own tests. Use it to explore a problem and explain a result, then verify the result yourself.

For situations requiring guaranteed expert oversight, we highly recommend our [human mentoring](./0.4. Mentoring.md) service, which provides a perfect blend of AI-driven efficiency and human expertise.

### What happened to the MLOps Coding Assistant?

The MLOps Coding Assistant, a hosted chatbot that answered questions about the course, was retired in October 2026. Coding agents can now read the course and work in your project directly, so the MLOps Coding Skills replace it.
